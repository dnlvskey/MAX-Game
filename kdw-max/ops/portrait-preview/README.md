# Превью вертикального стенда (вариант C)

Временный инструмент для просмотра раскладки C на экране 1080×1920 до пересборки `www/webgl-v5/app.js`.

Сборку из гита сейчас не пересобрать: в публикации нет шести модулей (`kdw-contact-area`, `kdw-activity-arrivals`, `activity-webgl/activity-popup-motion`, `kdw-music-player`, `kdw-standby-videos`, `kdw-device-brightness`). Поэтому превью берёт готовую `app.js` из репо и в памяти вносит в неё изменения этой ветки: вертикальный профиль, столбиковую раскладку и вертикальное меню. Файлы на диске не меняются.

## Запуск

Нужен Node.js 24, из папки `kdw-max`:

```bash
node ops/portrait-preview/preview.mjs
```

Откройте в Chrome адрес, который выведет команда, перетащите окно на вертикальный монитор и нажмите F11. Миссия запускается касанием плитки, затем касанием ладони.

## Отличия от стенда

- Без лаунчера: нет звука, стелы, связи со стелой и операторских настроек. Кнопка «Назад» и логотип MAX видны, потому что это не production-режим.
- В меню нет видео: видеофайлов меню нет в репо.
- Превью дополнительно масштабирует радиус касания из `kdw-contact-area` под ширину 1080. Исходник этого модуля в гите отсутствует, поэтому правку нужно перенести в него при пересборке.

После `npm run build:max` с полной рабочей копией этот инструмент не нужен.
